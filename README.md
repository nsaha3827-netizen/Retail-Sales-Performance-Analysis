
# 🛒 Retail Sales & Inventory Analysis

## 📌 Project Overview
This project analyzes a multi-store retail business to understand sales performance, profitability, and inventory efficiency. The goal is to generate actionable insights for better decision-making.

---

## 🎯 Objectives
- Analyze sales and profit trends over time
- Identify top and low performing products/categories
- Evaluate inventory efficiency across stores
- Understand customer purchase patterns

---

## 🗂️ Dataset Description
The dataset consists of:
- **Sales Table** – transaction-level data
- **Products Table** – product details and categories
- **Stores Table** – store-level information
- **Inventory Table** – stock availability
- **Calendar Table** – date hierarchy

---

## 🧠 Data Model
A **star schema model** was created using Power Pivot:
- Sales → Fact table
- Products, Stores, Calendar, Inventory → Dimension tables

---

## 📊 Key KPIs
- Total Sales: **13.12M**
- Total Profit: **3.66M**
- Profit Margin: **28%**
- Total Units Sold: **986.98K**
- Average Sales per Day: **21K**

---

## 🔍 Key Insights
- Sales declined by **24.62% YoY**, indicating reduced demand
- Profit dropped faster (**32.97%**) → margin pressure
- **Snacks** is the top-selling category, **Bakery** is lowest
- Sales are **weekday-heavy (68%)**
- Inventory is not fully aligned with sales demand
